# Stellar V1 Archive

This directory preserves the original Stellar/Soroban proof receipt prototype.
It is intentionally excluded from the active Next.js and contract build paths.

V1 demonstrated a Reclaim zkTLS proof flowing through a secp256k1 verifier and
then into a Soroban receipt contract. The archived implementation is retained
for research and migration reference; Base is the active public receipt chain
for Early V2.

Nothing in this directory is deployed or imported by the active application.
The archived Supabase migration is documentation only and must not be applied
to a new V2 deployment.
